# IT5016-A3-20267349-Repository3-OOP

# overview
Object Oriented programming designs. 
The programming in this repository focuses on the OOP concept of creating a scalable blueprint for managing large data systems.
The structure models data into classes of objects and initiates their specific attributes; defines the methods for executing tasks within the class.

# key features
*encapsulation* - data properties are initiated like private variables within the class and accessed via methods for retrieving and modifying information
*class-level list* - encapsulating the data into a class level list to store all created objects and update with the status/response method outputs
*reuse of code* - developing a class is facilitated by using code blocks from previous projects. The variables initiate the class attributes and the functions become the methods of the class.

# output
Developing a class in the code enables the businesses to store, organise and manage large database of separate entities in a structured and efficient way. Using OOP allows multiple objects to be created from the same class, each with its own private set of attributes. The methods gather user input information, compute calculations, evaluate rules, execute tasks and generate references.
The class structure makes the code more organised, reusable and easily updatable with the evolving requirements of businesses.
